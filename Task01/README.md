# Лабораторная работа 1

## Структура файлов данных

*   `genres.txt` – список жанров фильмов.
*   `movies.csv` – информация о фильмах (ID, название, жанры).
*   `occupation.txt` – список профессий пользователей.
*   `ratings.csv` – оценки фильмов пользователями (userId, movieId, rating, timestamp).
*   `tags.csv` – теги, присвоенные пользователями фильмам.
*   `users.txt` – информация о пользователях (ID, пол, возраст, профессия).
