# Лабораторная работа 2: ETL-процесс

## Описание
Скрипт `make_db_init.py` читает данные из файлов и генерирует SQL-скрипт `db_init.sql`.
Скрипт `db_init.bat` запускает Python-утилиту и создает базу данных SQLite `movies_rating.db`.

## Требования к окружению
* Python 3.x
* SQLite (утилита `sqlite3`)
